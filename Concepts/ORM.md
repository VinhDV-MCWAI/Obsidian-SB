ORM sẽ là lớp trung gian chuyển đổi các thao tác thành data access query đến db, giúp chuẩn hóa, clean hơn, dễ bảo trì hơn, dễ đọc, dễ thực hiện bảo mật hơn tránh sql injection.. Nhưng nó có nhiều hạn chế cho các case không xử lý được phải sql thuần: sql phức tạp không chuyển hóa được hoặc chuyển hóa khó hiểu hơn, sql công suất lớn hơn cho truy vấn nặng, Vấn đề loop query nền phải dùng eager loading để thay thế, ORM thường sinh ra các query thừa,….
