# Bản đồ: <tên dự án>

> Đề mục cho khối **Bản đồ** của dự án, AI tạo lúc [[Khởi tạo dự án]]. AI đọc file này đầu mỗi việc vừa / lớn để mở **đúng** tài liệu và code, không khám phá lại. Đường dẫn thay vì chép nội dung; code đổi chỗ → sửa một dòng. Cập nhật: <YYYY-MM-DD>.

## Tổng quan

<3–5 dòng: dự án làm gì, cho ai, luồng chính.>

## Tài liệu ↔ code

Kiểm tra lệch tài liệu ([[Công cụ và hook của dự án]]) dựa vào bảng này: mỗi dòng nối tài liệu với thư mục / file code, đường dẫn tính từ gốc repo, viết theo một định dạng cố định để máy đọc được. Code đổi → tài liệu cùng dòng được báo cần xem lại.

| Phần / tính năng | Tài liệu | Code | Ghi chú |
|---|---|---|---|
| <Đăng nhập> | `<đường dẫn tài liệu>` | `<thư mục code>`, `<file code>` | <khác tri thức cá nhân ở đâu, bẫy> |
